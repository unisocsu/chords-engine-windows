OPEN SOURCE PROJECT

קוד פתוח.
פיתוח מתמשך.

ChordsEngine Windows הוא fork והמשך פיתוח של מנוע האקורדים והמילים המקורי שנבנה באמצעות Claude Code על ידי @tsoolgee.

הריפו כולל את מנוע הניתוח, ממשק Windows, אריזה ל-EXE, מתקינים, מודלי Whisper, בדיקות ו-GitHub Actions לבנייה אוטומטית.
